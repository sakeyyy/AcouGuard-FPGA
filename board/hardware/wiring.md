# 当前运行版本接线

权威对应关系来自本包 test.xdc。原理图/PCB PDF 保留的是用户原图，右后标注存在历史互换，不要仅按符号位号判断物理方位。前方靠近 AX7021，后方靠近屏幕，前后/左右中心间距均按团队给定的 60 mm。

INMP441 的 L/R 均接地，表示取 I2S 左槽，并不表示物理左侧。四条 SD 独立；电源 3.3 V，共地。J15-39/40 为 3.3 V、37/38 为 GND；J15-2 为 5 V，不能接入麦克风或屏幕逻辑输入。

马达由 YYNMOS-4 驱动，不由 FPGA IO 供电。采购记录为 3 V 马达，负载电源应按实际马达额定值和启动电流配置；不要把旧 XDC 中的 5 V 示例当成已核定供电。按驱动模块实物端子接法核对逻辑参考地和负载供电。

KEY1 属于 PS MIO11，不写入 PL XDC。触摸引脚在当前版本未启用。

schematic.pdf / pcb.pdf 是原始生产/设计资料，不能单靠 PDF 完成重新制板；需修改 PCB 时应另保留原 CAD 项目及生产文件。当前包用于复现既有实物与代码。
